verified and extracted into the user's application-data directory.

Bundled in LayerLab.app:

- Tauri v2
- The system WebKit WebView provided by macOS
- Rust crates used by the Tauri shell, including reqwest, serde, sha2, tar,
  zip, zstd, flate2, and Tauri plugins
- LayerLab runtime pack containing Python and Python package dependencies

Prepared or downloaded during first-run setup / first use:

- Python
- FastAPI
- Uvicorn
- yt-dlp
- Demucs
- PyTorch / Torch
- torchaudio
- librosa
- Beat This! (MIT), including published model weights downloaded on first use
- music21 (BSD-3-Clause)
- pyloudnorm
- soundfile
- imageio-ffmpeg (BSD-2-Clause code only; its wheel-embedded GPL FFmpeg
  executable is removed from the packaged runtime)
- FFmpeg and ffprobe 8.1.1-tessus from evermeet.cx, downloaded directly and
  built with --enable-gpl --enable-version3 (GPL-3.0-or-later)
- Demucs model weights, not covered by the Demucs MIT code license; upstream
  describes them as personal/research-use artifacts
- Beat This! model weights

The release build generates the following from the exact packaged Python
runtime and target-specific Rust dependency graph:

- THIRD_PARTY_NOTICES.txt: complete component/version/license inventory
- THIRD_PARTY_LICENSES.txt: full collected license and notice texts
- THIRD_PARTY_INVENTORY.json: machine-readable component-to-text mapping
- pip-list.json: Python package/version inventory

The build fails when a packaged Python/Rust dependency has no declared license
or usable license text. Model terms and runtime downloads remain separate from
the Apache-2.0 license covering LayerLab/StemDeck code.
